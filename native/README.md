# ハムスターFPS — C++ネイティブ版(macOS / Linux)

Web版(`index.html`)の**射撃訓練場**をC++で移植したネイティブアプリです。
ブラウザのオーバーヘッドなしで動くため、Macで高フレームレート(通常ProMotionの120fps上限まで)で遊べます。

## ビルド方法(macOS)

```bash
# 依存のインストール(Homebrew)
brew install cmake glfw

# ビルド
cd native
cmake -B build
cmake --build build

# 実行
./build/hamfps
```

Apple Silicon / Intel どちらでも動きます(OpenGL 2.1互換プロファイル使用)。

## 操作

| 入力 | 動作 |
|---|---|
| WASD | 移動 |
| Shift | ダッシュ |
| C | 匍匐(トグル) |
| マウス | 視点 |
| 左クリック | 射撃 |
| 右クリック | 覗く(ADS・トグル) |
| R | リロード |
| 1 / 2 / 3 | 武器切替(G18 / M416 / Kar98) |
| ESC | マウスキャプチャ解除/再開 |

HP・弾数・スコアは**ウィンドウのタイトルバー**と画面下のマガジンバーに表示されます。

## 実装されている内容

- Web版と同じアルゴリズムの地形生成(ノイズ+山+外周リム)、湖、木、岩
- 武器3種(マガジン/予備弾/自動+手動リロード/反動/拡散/ADSズーム)
- 重力つき弾道・トレーサー・着弾パフ
- 風船(常時スポーン・撃つとスコア)
- ハムスターの的×5(倒すとコテンと転がり、2.5秒で復活)
- ダッシュ/匍匐/水中の移動速度変化、障害物コリジョン

## Web版との差分(v1の制限)

| 機能 | 状態 | 理由・today |
|---|---|---|
| P2P対戦 | ❌ | ブラウザのWebRTC相当をC++で持つのは大規模(将来: ENet/UDP直結でのLAN対戦が現実的) |
| GLBモデル(ハムスター/木) | ❌ | v1は手作りプリミティブ。tinygltf導入で対応可能 |
| サウンド | ❌ | miniaudio(1ヘッダ)導入で対応可能 |
| アイテム・バッグ・アタッチメント | ❌ | 訓練場スコープ外(武器は最初から3種所持) |
| 建物(家・工場) | ❌ | 同上 |

## 備考

- Linuxでも同じ手順でビルドできます(`apt install libglfw3-dev` 等)
- macOSのOpenGLは非推奨扱いですが、全Macで動作します。将来的にMetal/wgpuへの移行余地あり
